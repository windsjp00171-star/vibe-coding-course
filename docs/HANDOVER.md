# 交接說明：Vibe Coding 實戰課網站

> 寫給「接手的人」，假設你不會寫程式。
> 照著這份做，就能讓網站繼續運作、把資料備份好，必要時也能把它停掉。
> 這份文件**不包含任何密碼或金鑰**。那些東西只存在原講師的密碼管理器裡，要當面交接。

---

## 1. 這是什麼

一個給上班族的 AI 課程網站，內容包含：

- 課程教材
- 報名表
- 學員登入與學習進度
- 講師後台
- 結業證書查證

網站本身是免費的靜態網頁，資料存在一個雲端資料庫。平常**不需要寫程式**，所有日常工作都在網站的「講師後台」完成。

## 2. 東西放在哪裡

| 東西 | 放在哪裡 | 用途 |
|---|---|---|
| 網站 | GitHub Pages：`https://windsjp00171-star.github.io/vibe-coding-course/` | 學員和訪客看到的網站 |
| 網站的原始檔 | GitHub 的 `vibe-coding-course` 儲存庫（公開） | 改網站內容時才會用到 |
| 資料庫 | Supabase 上的「課程」專案 | 會員、班級、進度、報名、留言、證書 |
| 講師教材 | Supabase 的私人儲存空間 `teacher-files`，以及講師私人的 GitHub 儲存庫 | 簡報、Kahoot 題庫、學習手冊、講座檔案（學員看不到） |
| Google 登入 | Google Cloud 上的一個專案 | 讓學員用 Google 帳號登入 |

> ⚠️ 原講師的 Supabase 帳號裡**還有別的專案**（例如教會的系統）。操作時請確認左上角選的是「課程」專案，**不要動到其他專案**。

## 3. 接手前要拿到的權限

請原講師把你加進下面四個地方。四個都要，缺一個就會有事做不了：

1. **GitHub**：`vibe-coding-course` 儲存庫的協作者（Collaborator）
2. **Supabase**：課程專案所在組織的成員
3. **Google Cloud**：登入用的那個專案的成員
4. **網站講師身分**：原講師在講師後台「會員管理」輸入你的 Google Email，你第一次登入就會變成講師

## 4. 日常工作（都在講師後台，網址是網站的 `teacher.html`）

| 要做的事 | 在哪裡 |
|---|---|
| 讓學員看得到完整課程 | 講師後台 →「👥 會員管理」→ 把學員設為「已開通」 |
| 開一個新班、拿加入碼給學員 | 講師後台 →「🏫 班級」 |
| 看報名名單、候補遞補 | 講師後台 →「📝 報名管理」 |
| 開新的報名梯次 | 用 Supabase 的 SQL Editor 執行 `supabase/new-cohort.sql`（檔案裡有中文說明，改日期、名額、費用再執行），然後回講師後台按「開放報名」 |
| 回覆聯絡表單的留言 | 講師後台 →「✉️ 聯絡留言」，回覆完按「標記已回覆」 |
| 上傳或下載教材 | 講師後台 →「📁 教材下載」 |
| 看學員卡在哪個單元 | 講師後台 →「🧭 卡關分析」 |

## 5. 備份（每個月一次，開班前後各一次）

1. 登入講師後台 →「📊 總覽」→「📦 資料備份」→ 按 **「一鍵匯出全部資料」**。
2. 會下載一個檔案，檔名像 `vibe-course-backup-2026-09-27.json`，把它存到你的雲端硬碟。
3. 同一張卡片上，按 **「下載離線閱讀器」**，把 `backup-reader.html` 一起存在旁邊。這個只要做一次。
4. 要看備份內容時：雙擊 `backup-reader.html`，選那個 `.json` 檔。**不用網路、不用登入**，就能看到會員、報名、留言等資料，也能存成 Excel 打得開的 CSV。

另外建議：

- **教材檔案**不在備份檔裡，只有檔名。請另外從「📁 教材下載」把檔案下載保存。
- **完整的資料庫備份**：Supabase 的 Database → Backups 會自動保留。如果要搬到新的 Supabase 專案，需要找懂技術的人協助。

## 6. 萬一出事

| 狀況 | 可能原因 | 怎麼處理 |
|---|---|---|
| 網站打不開 | GitHub Pages 暫時故障，或儲存庫被改成私人 | 到 GitHub 的 `vibe-coding-course` → Settings → Pages，確認有開啟 |
| 網站打得開，但登入、報名、進度都不能用，頁面出現「會員功能載入失敗」 | Supabase 免費方案**一段時間沒人使用會自動暫停** | 登入 Supabase → 選課程專案 → 按「Restore」恢復，等幾分鐘 |
| 按 Google 登入出現錯誤 | Google 登入的設定被改動或過期 | 請懂技術的人對照 `docs/SETUP-MEMBERS.md` 第 3 節檢查 |
| 聯絡表單顯示「尚未啟用」 | 資料表還沒建立 | 在 Supabase SQL Editor（課程專案）執行 `supabase/add-contact.sql` |
| 報名頁看不到梯次 | 梯次沒開放，或權限設定沒跑 | 講師後台「📝 報名管理」按「開放報名」；還是不行就執行 `supabase/fix-grants.sql` |

## 7. 如果要停掉這個網站

1. 先做一次第 5 節的完整備份。
2. 告知目前的學員。證書查證頁停掉後就查不到了，建議提前一個月公告。
3. GitHub 的 `vibe-coding-course` → Settings → Pages → 關閉，網站就下線了。
4. 學員個資（姓名、Email、電話）：確認不再需要後，在 Supabase 刪除課程專案。**刪除後無法復原**，請確定備份已經存好。

## 8. 個資提醒

報名名單、聯絡留言裡有真實的姓名、Email、電話：

- 備份檔不要傳到公開的地方，也不要用 LINE 群組傳。
- 匯出的 CSV 用完就刪。
- 網站的隱私權政策（`privacy.html`）寫了「只用來處理報名與回覆詢問」，接手後也要遵守。
