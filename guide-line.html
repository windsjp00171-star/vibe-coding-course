LINE Developers 從零開始：
每一步按哪裡

LINE 場的 AI 小秘書，要先在 LINE 開一個「官方帳號」給它住。這一頁假設你從來沒用過 LINE Developers，一步一步帶你做。右邊示意圖的紅框和號碼就是要按的地方。

示意圖是簡化過的畫面，不是真的截圖；LINE 偶爾會改按鈕的名字或位置，也可能是英文或中文介面。找不到的話，把你的畫面截圖給講師看。

這一頁只帶你點「平台的按鈕」。註冊帳號、開專案、抄鑰匙這些事，本來就要自己在 LINE Developers 的網頁上點。真正做東西的部分（改功能、找錯誤），一樣交給 Claude Code：每一步都附一句「卡住時對 Claude Code 說」，你負責把狀況講清楚、最後自己驗收。最快的講法：畫面截圖（PrtSc）→ 在 Claude Code 貼上（Ctrl+V）→ 說一句你卡在哪（講師的三個鍵）。

00
開始之前

先認識 5 個名詞

看不懂也沒關係，做的時候回來查。

LINE DevelopersLINE 給開發者用的後台（developers.line.biz）。用你自己的 LINE 帳號就能登入，免費。
Provider一個「資料夾」，放同一個單位的所有 LINE 設定。通常用你的名字或單位名稱。
Channel資料夾裡的一個「東西」。小秘書是 Messaging API channel；LINE 登入是 LINE Login channel。
官方帳號使用者在 LINE 上看到、加好友的那個帳號。小秘書就「住」在這裡。
Channel secret／存取權杖兩個秘密：一個用來確認訊息真的是 LINE 送來的，一個讓程式能回話。小秘書的放 Vercel 的環境變數；登記系統的 LINE 登入放 Supabase 的 Secrets（單元 06）。
要準備：手機上的 LINE、一台電腦、大約 30 分鐘、一個記事本（拿到的秘密先存這裡，部署時一次貼進 Vercel）。第 6、8 步要等小秘書部署好，看圖解：Vercel。
01
一步一步

讓小秘書住進 LINE

每做完一步，勾一下「我做完了」，下次回來就知道做到哪。

1登入 LINE Developers

  1. 電腦打開 developers.line.biz，按右上角 Log in to Console ①
  2. 選 用 LINE 帳號登入 ②，手機上的 LINE 會跳出確認，按同意（或掃 QR code）
  3. 第一次登入會要你填開發者名稱和 Email，填好、同意條款

用你自己的 LINE 帳號就可以，不用另外申請。

🤖 卡住時對 Claude Code 說：「我第一次登入 LINE Developers，它要我填開發者名稱和 Email，這些會被誰看到？填什麼比較好？」

2建一個 Provider（資料夾）

  1. 登入後按 Create a new provider（或 Providers 旁的 Create）①
  2. Provider name 填你的名字或單位 ②，例如「王小明的小秘書」
  3. 按 Create ③
⚠️ 課後幫登記系統加裝 LINE 登入時，登入（LINE Login）和發通知的官方帳號（Messaging API）一定要建在同一個 Provider 底下。放在不同資料夾，LINE 給的使用者代號會不一樣，通知會送不到，而且不會有任何錯誤訊息。

🤖 卡住時對 Claude Code 說：「Provider 要取什麼名字？LINE 登入和發通知的官方帳號為什麼一定要放在同一個 Provider？請用白話說明。」

3建官方帳號（Messaging API channel）

  1. 進到剛剛的 Provider，按 Create a Messaging API channel ①
  2. 畫面會帶你到 LINE Official Account Manager 建一個官方帳號：填帳號名稱 ②（使用者會看到，例如「小明的小秘書」）、Email、業種（選「個人」或最接近的就好）
  3. 建好之後，在 Official Account Manager 右上角 設定 → Messaging API → 啟用 Messaging API ③，選剛剛的 Provider
  4. 回到 LINE Developers，Provider 裡就會多一個 Messaging API channel ④

官方帳號是使用者看到的那個 LINE 帳號；Messaging API 讓你的程式可以收訊息、回訊息。

🤖 卡住時對 Claude Code 說：「我在建 LINE 官方帳號，畫面問業種和帳號名稱（描述你看到的）。帳號名稱之後改得了嗎？使用者會看到什麼？」

4抄下 Channel secret（秘密）

  1. LINE Developers → 點你的 Messaging API channel
  2. 選 Basic settings 分頁 ①
  3. 往下捲到 Channel secret ②，按旁邊的複製
  4. 先存到記事本，標上 LINE_CHANNEL_SECRET=；部署時貼進 Vercel 的環境變數（圖解：Vercel 第 3 步）
🚫 秘密只貼到 Vercel 的環境變數：不要貼進程式、不要貼到 GitHub、不要傳到 LINE 群組。不小心外流就按旁邊的 Issue 換一把新的（單元 06：換鎖）。

🤖 卡住時對 Claude Code 說：「Channel secret 是做什麼用的？萬一我不小心貼到 GitHub 了，要怎麼處理？（不要叫我把 secret 貼給你）」

5發一把存取權杖（秘密）

  1. 同一個 channel，換到 Messaging API 分頁 ①
  2. 捲到最下面的 Channel access token (long-lived) ②
  3. 按 Issue ③，出現一長串字，複製
  4. 一樣先存到記事本，標上 LINE_CHANNEL_ACCESS_TOKEN=

有了這把，你的程式才能回訊息、主動推提醒。

🤖 卡住時對 Claude Code 說：「Channel access token 和 Channel secret 有什麼不一樣？各要放到 Vercel 環境變數的哪個名稱？（不要叫我把值貼給你）」

6接上 Webhook（把訊息送到你的程式）

先照圖解：Vercel把小秘書部署好。之後有兩種接法，用 A 就好：

  1. A. 設定精靈一鍵接好：打開 https://你的網址.vercel.app/setup.html，第 3 張卡按 一鍵設定 Webhook ①
  2. B. 自己貼：Messaging API 分頁 → Webhook URL 旁按 Edit ②，貼上 https://你的網址.vercel.app/api/webhook，按 Update → Verify，出現 Success 就對了
  3. 確認下面的 Use webhook 是打開的 ③
⚠️ Verify 失敗常見原因：網址打錯一個字（結尾是 /api/webhook）；Vercel 的 LINE_CHANNEL_SECRET 和第 4 步的不一樣；改了環境變數卻沒有 Redeploy。

🤖 卡住時對 Claude Code 說：「我按 Webhook 的 Verify 出現這個錯誤：（貼上）。請列出最可能的三個原因，一個一個帶我檢查。」

7關掉官方帳號的「自動回應」

  1. Messaging API 分頁中間的 Auto-reply messages 旁按 Edit，會打開 Official Account Manager
  2. 找到 回應設定 ①
  3. 聊天、自動回應訊息：都關掉 ②
  4. Webhook：打開 ③

沒關的話，官方帳號會搶著回「感謝您的訊息」這種罐頭訊息，小秘書的回覆會被蓋過去。

🤖 卡住時對 Claude Code 說：「我的官方帳號一直回「感謝您的訊息」，小秘書的回覆被蓋過去了。請帶我找到要關掉的設定。」

8加好友，讓小秘書認得你（設定主人）

  1. Messaging API 分頁上方有一個 QR code ①（設定精靈第 2 張卡也有「加小秘書好友」按鈕），用手機 LINE 掃描 → 加入好友
  2. 傳任何一句話，例如「你好」②
  3. 小秘書會回你一串 U 開頭的代號 ③：這是你的 LINE userId
  4. 把它加到 Vercel 的環境變數 LINE_USER_ID，再 Redeploy（圖解：Vercel 第 5 步）
  5. 再傳「明天下午三點開會」，應該回你已經記下來了

小秘書是私人的：設好主人之後，別人就算加了好友、傳訊息，它也不理、不會寫進你的資料庫，更不會用掉你的 AI 額度。

⚠️ 完全沒回應：先看圖解：Vercel 第 7 步的 Logs，再打開設定精靈看哪一張卡不是綠色。

🤖 卡住時對 Claude Code 說：「我傳訊息給小秘書，它完全沒有回。請帶我從 LINE 的回應設定、設定精靈、Vercel 的 Logs 一段一段檢查卡在哪裡。」

02
課後加裝

LINE 登入（讓登記系統用 LINE 登入）

只有要把單元 13 的課後加裝做起來的人才需要。一樣在同一個 Provider 底下。

A建 LINE Login channel

  1. 進到同一個 Provider，按 Create a new channel → LINE Login ①
  2. App types 勾 Web app ②，名稱、說明照填
  3. 建好後到 LINE Login 分頁 → Callback URL 填登記系統的網址 ③（和 Supabase 的 Site URL 完全一樣）
  4. Basic settings 抄下 Channel ID（可以公開，填進 config.js）和 Channel secret（秘密，放 Supabase Secrets）

🤖 卡住時對 Claude Code 說：「請讀 LINE.md，告訴我 LINE Login channel 的 Callback URL 要填什麼，還有 Channel ID 和 Channel secret 各要放在哪裡。」

B連上官方帳號，再公開

  1. LINE Login channel → Basic settings → Linked LINE Official Account ① 選登記系統用來發通知的官方帳號（照 LINE.md 另外建一個，不要用小秘書那個：小秘書只理主人），這樣登入時會問使用者要不要加好友
  2. 頁面上方的狀態從 Developing 改成 Published ②，別人才登入得了（自己測試時可以先不改）

接下來照範本的 LINE.md 第 2～4 步，到 Supabase 放 line-login、line-notify 兩支小程式。

🤖 卡住時對 Claude Code 說：「Linked LINE Official Account 和 Published 各是做什麼的？沒設定的話會發生什麼事？」
