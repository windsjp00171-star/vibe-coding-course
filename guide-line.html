00
開始之前

先認識 5 個名詞

看不懂也沒關係，做的時候回來查。

LINE DevelopersLINE 給開發者用的後台（developers.line.biz）。用你自己的 LINE 帳號就能登入，免費。
Provider一個「資料夾」，放同一個單位的所有 LINE 設定。通常用你的名字或單位名稱。
Channel資料夾裡的一個「東西」。小秘書是 Messaging API channel；LINE 登入是 LINE Login channel。
官方帳號使用者在 LINE 上看到、加好友的那個帳號。小秘書就「住」在這裡。
Channel secret／存取權杖兩個秘密：一個用來確認訊息真的是 LINE 送來的，一個讓程式能回話。只放在 Supabase 的 Secrets（單元 06）。
要準備：手機上的 LINE、一台電腦、大約 30 分鐘，以及已經照圖解：Supabase建好的專案（第 6 步會用到它的網址）。
01
一步一步

讓小秘書住進 LINE

每做完一步，勾一下「我做完了」，下次回來就知道做到哪。

1登入 LINE Developers

  1. 電腦打開 developers.line.biz，按右上角 Log in to Console ①
  2. 選 用 LINE 帳號登入 ②，手機上的 LINE 會跳出確認，按同意（或掃 QR code）
  3. 第一次登入會要你填開發者名稱和 Email，填好、同意條款

用你自己的 LINE 帳號就可以，不用另外申請。

2建一個 Provider（資料夾）

  1. 登入後按 Create a new provider（或 Providers 旁的 Create）①
  2. Provider name 填你的名字或單位 ②，例如「王小明的小秘書」
  3. 按 Create ③
⚠️ 之後的小秘書（Messaging API）和 LINE 登入（LINE Login）一定要建在同一個 Provider 底下。放在不同資料夾，LINE 給的使用者代號會不一樣，通知會送不到，而且不會有任何錯誤訊息。

3建官方帳號（Messaging API channel）

  1. 進到剛剛的 Provider，按 Create a Messaging API channel ①
  2. 畫面會帶你到 LINE Official Account Manager 建一個官方帳號：填帳號名稱 ②（使用者會看到，例如「小明的小秘書」）、Email、業種（選「個人」或最接近的就好）
  3. 建好之後，在 Official Account Manager 右上角 設定 → Messaging API → 啟用 Messaging API ③，選剛剛的 Provider
  4. 回到 LINE Developers，Provider 裡就會多一個 Messaging API channel ④

官方帳號是使用者看到的那個 LINE 帳號；Messaging API 讓你的程式可以收訊息、回訊息。

4抄下 Channel secret（秘密）

  1. LINE Developers → 點你的 Messaging API channel
  2. 選 Basic settings 分頁 ①
  3. 往下捲到 Channel secret ②，按旁邊的複製
  4. 貼到 Supabase 的 Secrets，名稱 LINE_CHANNEL_SECRET（圖解：Supabase 第 7 步）
🚫 秘密只貼到 Supabase 的 Secrets：不要貼進程式、不要貼到 GitHub、不要傳到 LINE 群組。不小心外流就按旁邊的 Issue 換一把新的（單元 06：換鎖）。

5發一把存取權杖（秘密）

  1. 同一個 channel，換到 Messaging API 分頁 ①
  2. 捲到最下面的 Channel access token (long-lived) ②
  3. 按 Issue ③，出現一長串字，複製
  4. 貼到 Supabase 的 Secrets，名稱 LINE_CHANNEL_ACCESS_TOKEN

有了這把，你的程式才能回訊息、主動推提醒。

6接上 Webhook（把訊息送到你的程式）

先照圖解：Supabase 第 8 步放好 line-bot，拿到它的網址：https://你的專案代號.supabase.co/functions/v1/line-bot

  1. Messaging API 分頁 → Webhook URL 旁按 Edit ①，貼上網址，按 Update
  2. 按 Verify ②，出現 Success 就對了
  3. 把下面的 Use webhook 打開 ③
⚠️ Verify 失敗常見原因：網址打錯一個字；line-bot 的 Verify JWT 沒關；Supabase 的 LINE_CHANNEL_SECRET 和第 4 步的不一樣。

7關掉官方帳號的「自動回應」

  1. Messaging API 分頁中間的 Auto-reply messages 旁按 Edit，會打開 Official Account Manager
  2. 找到 回應設定 ①
  3. 自動回應訊息：關掉 ②
  4. Webhook：打開 ③

沒關的話，官方帳號會搶著回「感謝您的訊息」這種罐頭訊息，小秘書的回覆會被蓋過去。

8加好友，傳第一句話

  1. Messaging API 分頁上方有一個 QR code ①
  2. 用手機的 LINE 掃描 → 加入好友
  3. 傳「說明」②，小秘書應該回你用法 ③
  4. 再傳「5 分鐘後提醒我喝水」，等 5～10 分鐘收到 ⏰（排程要先照圖解：Supabase 第 9 步開好）
⚠️ 完全沒回應：先看圖解：Supabase 第 10 步的 Logs。有沒有出現紀錄、是不是紅色，就知道卡在哪一段。
02
課後加裝

LINE 登入（讓登記系統用 LINE 登入）

只有要把單元 13 的課後加裝做起來的人才需要。一樣在同一個 Provider 底下。

A建 LINE Login channel

  1. 進到同一個 Provider，按 Create a new channel → LINE Login ①
  2. App types 勾 Web app ②，名稱、說明照填
  3. 建好後到 LINE Login 分頁 → Callback URL 填登記系統的網址 ③（和 Supabase 的 Site URL 完全一樣）
  4. Basic settings 抄下 Channel ID（可以公開，填進 config.js）和 Channel secret（秘密，放 Supabase Secrets）

B連上官方帳號，再公開

  1. LINE Login channel → Basic settings → Linked LINE Official Account ① 選你的官方帳號，這樣登入時會問使用者要不要加好友
  2. 頁面上方的狀態從 Developing 改成 Published ②，別人才登入得了（自己測試時可以先不改）

接下來照範本的 LINE.md 第 2～4 步，到 Supabase 放 line-login、line-notify 兩支小程式。
