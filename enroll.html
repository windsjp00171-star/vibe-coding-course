01
先說清楚

這堂課適合誰、不適合誰

✅ 很適合

  • 工作上有重複雜事想自動化的行政、業務、企劃、老師、NPO 同工
  • 用過 ChatGPT，但不知道怎麼讓它「真的做出東西」的人
  • 需要一個內部小工具，但排不進公司 IT 排程的人
  • 想知道 AI 用在公司裡，哪些事不能做的主管

🚫 不太適合

  • 已經會寫程式、想學框架或演算法的人（這堂課會太慢）
  • 想做金流、醫療、個資敏感系統的人（課程會教你為什麼先別碰）
  • 只想聽觀念、不想動手的人——全程有一半時間在操作
需要什麼：一台 Windows 或 Mac 筆電、一個 Claude 付費方案（單元 2 會教怎麼選）、以及一個你自己想解決的小問題。

安裝與第一次上線是最容易超時的兩段，課表已經預留緩衝。結業作品就是你從第一堂課開始想的題目：半天 C 先裝好有登入、有門禁的登記系統，半天 D 留 90 分鐘讓你在講師身邊把它改成自己的。另有可加選的第五個半天 LINE 場（見下方）。其他 D 段選修（手機 App、資料整理、AI 詐騙防範等）結業後可以自學。

💬 LINE 場（第五個半天，可加選）：做一位 AI 小秘書

在 LINE 上隨口傳一句「明天下午三點跟阿秦開會」，它就記成提醒，時間到了用 LINE 叫你；每天早上 7 點推早安簡報。這是講師天天在用、而且開源的工具，LINE 場帶你 Fork 一份，做出你自己的那一位。

  • 設計並改成你的：你的小秘書要幫誰、懂哪幾種話、最重要的規則、回覆口氣，講給 Claude Code 聽讓它改（小組出席、進度追蹤、值班提醒都可以）
  • 上工：LINE 建官方帳號、Supabase 存資料、Vercel 放程式，設定精靈逐項變綠色；AI 用免費的 Gemini，不用先儲值（要放個資時改用付費層）
  • 安全與成本：檢查訊息真的來自 LINE、只回應你一個人、鑰匙只放伺服器、AI 額度用完主動通知；還有講師的小秘書壞過的四次

結業後，也可以照講義自己把「用 LINE 登入」和「狀態改變時 LINE 通知」加到半天 C 的登記系統。場次開課時公布，可以先用下方的聯絡表單登記意願。

每個單元都有三段時間：課前自學（在家打開網站）、課中實作（教室裡動手，就是實際上課時數）、課後任務（回家做一件真的事）。 必修合計約 — 小時，其中課中實作約 — 小時，通常安排成四個半天。D 段選修可依班級需求挑選。

05
為什麼是這堂

和其他 AI 課程的差別

🎮 會動手的模擬器

7 個模擬關卡：改壞了怎麼救回來、金鑰外洩的那一晚、老闆視訊叫你匯款。在模擬裡踩坑，不用在真的專案上踩。

🕳️ 27 個真實的坑

全部來自講師實際做過的專案：時區差 8 小時、備份只備到 17%、推播半夜吵醒所有人。不是教科書案例。

🗣️ 全程白話

沒有背景知識也聽得懂。專業名詞有 67 個詞的小辭典，內文點一下就跳出白話解釋。

🩺 資安是必修

金鑰保護、AI 被騙、資料權限（誰看得到哪些資料）、上線前體檢，都在必修裡；deepfake 詐騙辨識在選修和半日資安課。做得出來還要不出事。

📘 紙本學習單

每單元 2～4 張 A4，可以手寫、可以帶回辦公室。不是只有投影片。

👀 講師看得到你卡在哪

後台會顯示全班在哪個單元過關率最低，下一堂課就針對那裡多講。

做過的，才拿出來教

課程裡的 27 個坑，也全部是這些專案修過的真實紀錄——包含半夜把所有人吵醒的推播，和以為備份好了其實只備到 17% 的那一次。

10
常見問題

你可能會想問

完全沒寫過程式，真的跟得上嗎？

這堂課就是為此設計的。全程不用背指令，你要做的是把需求講清楚、判斷要不要允許、以及親手驗收。課程裡所有專業名詞都有白話解釋。

要自己付 AI 的費用嗎？

要。Claude Code 需要 Claude 的付費方案，單元 2 會說明怎麼選、大概多少。這筆費用不含在學費裡，因為方案和價格會變動，由你自己申請比較彈性。

課後還能看教材嗎？

可以。課程網站會持續更新，你的帳號可以一直登入看，進度也會保留。

我做出來的東西，資料安全嗎？

課程有四個必修單元在講這件事（包括誰看得到哪些資料），也會明確告訴你哪些系統現階段不要自己做（金流、醫療、大量個資）。

可以只上其中幾堂嗎？

必修單元有前後順序，建議整套上。D 段選修（LINE、手機 App、資料整理、AI 詐騙防範）可以依需求挑。

公司要核銷，可以開發票或收據嗎？

（待填：說明可否開立發票／收據、抬頭與統編怎麼提供）
