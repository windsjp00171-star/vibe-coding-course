Supabase 從零開始：
每一步按哪裡

單元 10 的登記系統、LINE 場的小秘書，資料都放在 Supabase。這一頁假設你從來沒用過，一步一步帶你做。每一步右邊有一張示意圖，紅框和號碼就是要按的地方。

示意圖是簡化過的畫面，不是真的截圖；Supabase 偶爾會改按鈕的名字或位置。找不到的話，把你的畫面截圖給講師看。

這一頁只帶你點「平台的按鈕」。註冊帳號、開專案、抄鑰匙這些事，本來就要自己在 Supabase 的網頁上點。真正做東西的部分（改功能、找錯誤），一樣交給 Claude Code：每一步都附一句「卡住時對 Claude Code 說」，你負責把狀況講清楚、最後自己驗收。最快的講法：畫面截圖（PrtSc）→ 在 Claude Code 貼上（Ctrl+V）→ 說一句你卡在哪（講師的三個鍵）。

00
開始之前

先認識 5 個名詞

看不懂也沒關係，做的時候回來查。

Supabase一個雲端服務：幫你放資料（資料庫）、管登入、跑後端小程式。免費方案就夠上課用。
專案（Project）一個系統開一個專案。登記系統一個、小秘書一個，不要混在一起，更不要用到教會或公司的正式專案。
SQL跟資料庫說話的語言。你不用會寫，範本都寫好了，只要「貼上、按 Run」。
兩把鑰匙公開鑰匙（publishable／anon）可以放網頁；萬能鑰匙（secret／service_role）絕對不能給任何人（單元 06、10）。
Edge Function（後端小程式）放在 Supabase 上跑的程式，需要秘密鑰匙的事在這裡做，網頁看不到鑰匙。登記系統加裝 LINE 登入時才用得到；小秘書的程式放在 Vercel。
要準備：一個 GitHub 帳號（單元 04 註冊過的）、大約 30～60 分鐘、一個可以記密碼的地方（密碼管理器或手機的備忘錄都可以，不要記在會公開的地方）。
做 LINE 小秘書的人：只要做第 1～4 步和第 6 步。第 3 步貼的是小秘書的 supabase/schema.sql，第 4 步拿的是另一把鑰匙，看清楚那一步的說明。
01
一步一步

跟著做

每做完一步，勾一下「我做完了」，下次回來就知道做到哪。

1註冊 Supabase

  1. 打開 supabase.com
  2. 按右上角的 Start your project（或 Sign in）①
  3. 選 Continue with GitHub ②，用你的 GitHub 帳號登入，按同意

為什麼用 GitHub 登入？少記一組密碼，之後上線也用同一個帳號。

🤖 卡住時對 Claude Code 說：「我要註冊 Supabase，畫面上看到這些選項（貼上或描述你看到的），我該按哪一個？為什麼？」

2建一個新專案

  1. 按 New project ①
  2. Name：取你的作品名，例如 my-signup
  3. Database Password：按 Generate a password ②，然後把密碼存到密碼管理器（平常用不到，但弄丟會很麻煩）
  4. Region（地區）：選 Northeast Asia (Tokyo) 或 Singapore ③，離台灣近比較快
  5. 按 Create new project ④，等 1～2 分鐘，畫面跑完就好了
⚠️ 免費方案最多兩個專案，而且一週沒人用會自動暫停。暫停後到專案頁按 Restore 就能恢復，資料還在。

🤖 卡住時對 Claude Code 說：「我在 Supabase 建新專案，Region 有好幾個選項，住在台灣的使用者選哪個比較好？資料庫密碼要怎麼保管？」

3貼上 SQL，建好資料表和門禁

  1. 用記事本打開範本裡的 setup.sql（小秘書是 GitHub 上的 supabase/schema.sql），全選、複製
  2. Supabase 左邊選單按 SQL Editor ①
  3. 按 New query（或 ＋）②，把剛剛複製的貼到中間的大框框
  4. 按右下角的 Run ③
  5. 下面出現 Success. No rows returned ④ 就成功了

這一步會建立「放資料的表格」和「誰能看什麼」的門禁規則（RLS）。

⚠️ 登記系統的 setup.sql：最後一行的 Email 要先換成你自己的，你才會是管理者。
⚠️ 小秘書的 schema.sql 可以重複執行，已經建好的表不會被影響。
⚠️ 出現紅色錯誤？把錯誤訊息整段複製給 Claude Code 或講師看。

🤖 卡住時對 Claude Code 說：「我在 Supabase 的 SQL Editor 貼上 setup.sql 按 Run，出現這個錯誤：（貼上錯誤）。請先用白話說明原因，不要直接改檔案。」

4找到網址和鑰匙

  1. 左下角按 齒輪（Project Settings） ①
  2. 選 API Keys（有的版本叫 API）②
  3. 複製 Project URL ③（https://一串字.supabase.co）
  4. 登記系統：複製 publishable 那一把 ④（sb_publishable_ 開頭；舊版叫 anon public），貼進範本的 config.js
  5. LINE 小秘書：複製 secret 那一把 ⑤（舊版叫 service_role），存到記事本標上 SUPABASE_SERVICE_KEY=；Project URL 標上 SUPABASE_URL=
🚫 secret／service_role 是萬能鑰匙 ⑤：它能繞過所有門禁。登記系統絕對不要複製它；小秘書的程式在伺服器上跑，才可以用，而且只能貼進 Vercel 的環境變數，不能進網頁、config.js、GitHub 或任何聊天室。

🤖 卡住時對 Claude Code 說：「我手上有 publishable 和 secret 兩把鑰匙。登記系統的 config.js 要貼哪一把？為什麼 LINE 小秘書反而要用 secret，而且只能放在 Vercel？（不要叫我把值貼給你）」

5告訴 Supabase 你的網站網址（登記系統）

  1. 左邊按 Authentication ①
  2. 選 URL Configuration ②
  3. Site URL 填你的網站網址 ③，例如 https://你的帳號.github.io/my-signup/，按 Save
  4. Redirect URLs 按 Add URL ④，再填一次同一個網址，按 Save

登入信裡的連結會帶人回到這個網址。沒設的話，點信會跑到錯的地方。

⚠️ 網址要一模一樣，結尾的 / 也算。

🤖 卡住時對 Claude Code 說：「我點了登入信的連結，卻跑到錯的網址（貼上網址）。請一步一步帶我檢查 Supabase 的 URL Configuration 該填什麼。」

6看資料有沒有真的存進去

  1. 左邊按 Table Editor ①
  2. 點資料表名稱 ②（登記系統是 entries，小秘書是 notes）
  3. 右邊就是一筆一筆的資料，像 Excel ③
  4. 要備份：右上角 Export → CSV ④

網站或小秘書說「送出了」，到這裡看得到才算真的存起來。

🤖 卡住時對 Claude Code 說：「網站說「送出了」，但我在 Table Editor 看不到資料。請列出可能的原因，一項一項帶我檢查。」

7放秘密鑰匙（Secrets）

登記系統加裝 LINE 登入才需要（小秘書的鑰匙放 Vercel，不用這一步）。只用 Email 登入的話，跳到第 9 步。

  1. 左邊按 Edge Functions ①
  2. 選 Secrets ②
  3. Name 填名稱 ③（例如 LINE_CHANNEL_SECRET，大小寫、底線一個字都不能錯），Value 貼上值
  4. 按 Save ④。範本的 LINE.md 列了要放哪幾把，一把一把加

秘密鑰匙放這裡，後端小程式讀得到，網頁、GitHub、別人都看不到（單元 06）。

🤖 卡住時對 Claude Code 說：「請讀 LINE.md，列出我要在 Supabase Secrets 新增哪幾個名稱，每一個的值要去哪裡找。只列名稱，不要叫我把值貼給你。」

8放後端小程式（Edge Function）

  1. Edge Functions → Functions → Deploy a new function ①
  2. 選 Via Editor ②（在網頁上直接貼程式，不用裝任何東西）
  3. 名稱照範本 LINE.md 填 ③（例如 line-login，一個字都不能錯）
  4. 用記事本打開範本的 functions/名稱/index.ts，全選複製，取代編輯器裡原本的內容，按 Deploy ④
  5. 部署完進到這支小程式的設定，照 LINE.md 決定 Verify JWT 要不要關 ⑤
⚠️ Verify JWT（有的版本叫 Enforce JWT Verification）：line-login 要關掉；line-notify 保持開著。關錯了登入會失敗。
⚠️ 改了程式，要整份重新貼上再 Deploy 一次才會生效。

🤖 卡住時對 Claude Code 說：「我要把 functions/line-login/index.ts 部署到 Supabase 的 Edge Functions，請一步一步帶我，每一步等我說好了再繼續。Verify JWT 要開還是關？為什麼？」

9出問題時，去哪裡看錯誤

  1. Edge Functions → Functions → 點出問題的那一支 ①
  2. 選 Logs 分頁 ②
  3. 紅色的那幾行就是錯誤 ③。先把裡面的鑰匙、權杖換成 xxx，再截圖或複製給 Claude Code 或講師

LINE 登入失敗、通知沒送到，答案幾乎都在這裡。小秘書的錯誤不在這裡，看圖解：Vercel 第 7 步。

🤖 卡住時對 Claude Code 說：「這是 Edge Function 的 Logs（金鑰已經換成 xxx）：（貼上）。請用白話告訴我哪裡出錯、我下一步該檢查什麼。」
