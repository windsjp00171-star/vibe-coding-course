16 D 進階選修．AI 的工具箱

它為什麼能自己動手？
Agent、MCP 和 Skill

你已經用 Claude Code 做出東西了。這個單元回頭解釋它背後的四個零件：會自己規劃的 Agent、讓它連上外部工具的 MCP、把你的做事方法打包起來的 Skill，以及讓它定時自己跑的排程。懂了這些，你才知道它的能力邊界在哪，也才知道該在哪裡踩煞車。

  • 說得出 Agent 跟聊天機器人的差別
  • 知道 MCP 是什麼、裝之前要注意什麼
  • 知道 Skill 是什麼，以及跟 CLAUDE.md 的差別
  • 判斷哪些事適合交給自動排程
課前自學 約 25 分 課中工作坊 約 35 分 課後任務 約 15 分
01
核心觀念

Agent 就是會跑「小迴圈」的 AI

聊天機器人只做一件事：你問，它答。Agent 多了一個迴圈——它會自己看結果、自己決定下一步，直到任務完成或卡住。

🔁 這個迴圈長這樣

  1. 想：把你的任務拆成步驟
  2. 動手：開檔案、改檔案、執行指令、上網查
  3. 看結果：成功了嗎？報錯了嗎？
  4. 修正：錯了就改，再跑一次

你在 Claude Code 裡看到它「自己跑了好幾步」，就是這個迴圈在轉。

聊天型像顧問：給你建議，事還是你自己做。Agent 像請了一個助理：你說「幫我把這批報名表整理成統計表」，它自己開檔案、算、存檔，做完跟你回報。
代價是：它真的會動你的東西。所以 Claude Code 動手前會問「允許嗎？」——那個詢問不是囉唆，是你唯一的煞車（單元 2、單元 7 有練習）。

02
它的手腳

它能動手，是因為有「工具」

AI 本身只會產生文字。它之所以能改你的檔案，是因為有人給了它一組工具，並且教它怎麼用。

📖 讀

打開檔案來看、搜尋整個資料夾、上網查資料。風險低。

✏️ 寫

建立檔案、修改檔案、刪除檔案。動到的是你的電腦，要看清楚再允許。

⚡ 執行

跑指令、安裝套件、推上 GitHub。風險最高，看不懂就先拒絕。

一句話記住：AI 的能力＝它拿到的工具。給它的工具越多，它越好用，出事的範圍也越大。這就是「最小權限」在 AI 時代的樣子。
03
外接能力

MCP：給 AI 用的萬用轉接頭

MCP（Model Context Protocol）是一個共通規格，讓各種外部服務都能用同一種接法接給 AI 用。接上之後，AI 就多了一組新工具。

🌐 瀏覽器

讓它自己打開網頁、填表單、截圖確認畫面對不對。

🗄️ 資料庫

讓它直接查 Supabase 的資料、建資料表（單元 10）。

📅 行事曆／通訊

讓它讀行事曆、寄信、發訊息。

沒有 MCP 之前，每接一個服務都要另外寫一套接法。有了 MCP，就像所有電器都改用同一種插頭，插上去就能用。
裝之前先想三件事：
  • 來源可信嗎？裝一個 MCP 等於讓 AI 多一雙手，來路不明的別裝。
  • 它會拿到什麼權限？能不能刪資料、能不能花錢、能不能寄信給別人。
  • 它讀到的內容也可能在騙 AI。網頁和文件裡可以藏指令（單元 7 的提示詞注入），所以權限要給最小的。
04
把你的做法打包

Skill：寫給 AI 看的工作手冊

Skill（技能包）是一個資料夾，裡面放一份說明文件，告訴 AI「遇到這類工作時，照這個步驟做」，旁邊還可以附範本、腳本、檢查清單。AI 平常不會讀它，遇到相關的工作才打開來看。

🧰 一個 Skill 裡面有什麼

  • 什麼時候用：例如「要做投影片的時候」
  • 步驟：先做什麼、再做什麼、做完怎麼檢查
  • 範本或工具：現成的檔案、可以直接跑的小程式
  • 禁止事項：這件事不要這樣做

這門課的簡報就是這樣產生的：把「怎麼把網頁內容變成投影片」寫成固定流程，AI 每次照做，結果才會一致。

🆚 跟 CLAUDE.md 差在哪

CLAUDE.mdSkill
像什麼公司的員工守則某項工作的 SOP
什麼時候讀每次開工都先讀遇到這類工作才打開
內容整個專案的規矩單一種工作的步驟和範本
適合放命名規則、不准做的事、回報格式做投影片、寫週報、上線前檢查
為什麼要分開？因為 AI 的「桌子」就那麼大（單元 0）。守則每次都讀，所以要短；SOP 平常收起來，需要時才攤開，這樣既不佔空間，又不會漏步驟。

05
分身術

子代理：一件事分給好幾個 AI 同時做

大的任務可以交給幾個「子代理」同時處理，每個子代理有自己的一張桌子，做完把結論交回來。

✅ 適合

互不相干的事：一個查資安問題、一個查效能、一個整理文件。

⚠️ 不適合

會互相影響的事：兩個同時改同一個檔案，最後會打架。

💸 代價

同時跑好幾個，速度快，但用量也是好幾倍。小事不用出動。

像請三個實習生同時查三件不相干的資料，比一個人查三次快。但如果三個人改同一份文件，最後你要花更多時間收拾。
06
讓它自己跑

排程：不用你按開始

可以設定「每天早上八點自動做一件事」。判斷要不要這樣做，用下面兩個問題就夠了。

✅ 適合自動跑

  • 規則固定、結果可預期（整理資料、產生報表、檢查連結還通不通）
  • 出錯了不會造成傷害，頂多重跑一次
  • 有地方可以看它做了什麼

🚫 不要自動跑

  • 會寄信給別人、會付錢、會刪資料
  • 需要有人判斷的事
  • 你不會去看結果的事——沒人看的自動化，壞了也沒人知道
自動排程最常見的坑是時區：平台大多用國際標準時間，台灣快 8 小時，設錯就會在半夜跑、半夜發通知（單元 12、15 都踩過這個坑）。
07
課中工作坊

寫一個你自己的 Skill

挑一件你每個月都要重做一次的雜事，把它變成 AI 可以照做的 SOP。

  1. 0–10 分挑一件重複的雜事月報、出貨清單、活動公告、會議紀錄整理都可以。條件是：每次流程都差不多。
  2. 10–25 分寫下四件事什麼時候用、步驟一二三、要附什麼範本、哪些事不准做。用中文寫，不用管格式。
  3. 25–35 分請 Claude Code 照做一次把你寫的丟給它，請它照著做一次，然後問它：「哪一步我寫得不夠清楚？」再改。
