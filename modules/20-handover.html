20 C 資安．維運

三個月後，
你還救得回來嗎？

做出來、放上線，只是開始。真正會讓人放棄的，是三個月後打開自己的專案看不懂、電腦壞掉才發現備份是空的、或是某個免費服務突然收攤。這個單元把這三件事一次處理掉。

  • 做得出一份「三個月後的自己看得懂」的交接包
  • 分得清楚「有備份」和「救得回來」不是同一件事
  • 做過一次還原演練，知道自己真的救得回來
  • 知道服務下架或漲價時，怎麼把東西搬走
課前自學 約 20 分 課中工作坊 約 35 分 課後任務 約 15 分
01
先承認一件事

三個月後打開專案，你會忘光

這不是你記性不好。用 AI 協作的時候，很多決定是「當下講一講就過了」，沒有留下痕跡——所以忘掉是必然的，不是意外。

🤔 這個檔案在幹嘛

當初 AI 建了七個檔案，你只記得其中兩個。剩下五個不敢刪，也不敢改。

🧩 為什麼這樣做

「這裡不要用 X，因為會壞」——當時講過，現在只剩結果，理由不見了，於是三個月後又踩一次。

🔌 這要怎麼跑起來

要先裝什麼、密碼放哪、改完怎麼上線。換一台電腦就卡在第一步。

解法很土，但有效：把「三個月後會問的問題」在還記得的時候寫下來。下一段的三份檔案，就是在回答這三個問題。
02
交接包

三份檔案，救未來的你

不用寫得漂亮，寫得誠實就好。而且這三份都可以請 AI 幫你起草——它讀得到你的專案。

檔案回答什麼問題最少要寫什麼
README.md這是什麼、給誰用、怎麼跑起來一句話介紹、安裝步驟、上線步驟、聯絡人
CLAUDE.md下次叫 AI 改的時候，要注意什麼專案慣例、不能動的東西、踩過的坑
commit 訊息為什麼改成這樣改了什麼＋為什麼（單元 4 練過）
可以這樣請 AI 起草：「請讀完這個專案，幫我寫一份 README，假設讀的人是三個月後的我，已經忘記所有細節。要包含：這是什麼、怎麼在新電腦上跑起來、哪些檔案不能動、以及我們之前決定不做的功能。寫完先列給我看，不要直接建立檔案。」

為什麼要「先列給我看」：README 是給人看的，AI 會有寫得太漂亮、把沒做的事寫成做了的傾向。你要當那個說「這句不對」的人。

03
動手玩

你現在能承受哪一種災難？

勾選你「現在真的有」的備份層，下面會告訴你哪些狀況救得回來、哪些救不回來。

講師真的踩過：設定了自動備份，也看到「備份成功」，半年後要還原才發現——只備到 17%。因為備份工具遇到大檔案就默默跳過，而成功訊息照樣跳出來。沒有還原過的備份，只是一個讓你安心的假象。
04
最重要的一段

還原演練：假裝電腦壞了

挑一個不忙的下午，花 30 分鐘做一次。做過一次，你對自己的作品才真的有底氣。

  1. 步驟 1開一個新資料夾不要用原本的專案資料夾。假裝這是一台新電腦。
  2. 步驟 2只用 GitHub 上的東西把它拉下來不准從舊資料夾複製任何檔案。拉不下來的東西，就是你其實沒有備份的東西。
  3. 步驟 3照 README 一步一步跑卡住的地方，就是 README 漏寫的地方——當場補進去。
  4. 步驟 4補上不在 GitHub 的東西金鑰、環境變數、資料庫內容。這些本來就不該進 GitHub（單元 6），所以要另外記「它們放在哪、怎麼拿」。
  5. 步驟 5打開來確認真的會動跟正式版對一次。會動，才算演練成功。
05
另一種災難

你依賴的服務，有一天會消失

不是嚇你。講師的作品裡就有好幾個「線上版已下線」——有的是免費方案收掉，有的是服務整個關門。

⚠️ 會發生的事

  • 免費方案取消，變成要付費
  • 免費額度調降，你突然超量
  • 服務整個關閉，給你 30 天搬家
  • 帳號因為太久沒用被停用

✅ 平常就能做的準備

  • 資料能匯出：選服務時先確認「我能不能把資料整包拿走」
  • 定期匯出一次：資料庫每月匯出一份放自己電腦
  • 用標準格式：CSV、JSON 這種到哪都讀得懂的格式
  • 別把邏輯全寫在別人的平台裡：程式碼留在自己的 GitHub
挑服務時多問一句：「如果三年後我要搬走，我拿得走什麼？」拿不走的，就不要放重要的東西進去。
06
課中工作坊

做一次真的還原演練

用你自己上線的那個作品，當場演練一次。

👥 怎麼分組兩人一組，互相當對方的「三個月後的自己」

🎒 要準備你上線的作品、你的 GitHub 帳號、一個空資料夾

🎁 做完要交出補好的 README，以及一份「我還救不回來的東西」清單

重點不是演練成功，是找出你救不回來的東西。找到越多，這堂課越值得。

  1. 0–10 分請 AI 起草交接包用第 02 段的那段話，請 Claude Code 讀完專案寫 README 草稿，你逐句確認。
  2. 10–25 分交換演練把 GitHub 網址給隊友，讓他照你的 README 跑跑看。他卡住的地方，就是你漏寫的地方。
  3. 25–32 分列出救不回來的東西金鑰、資料庫內容、某個只存在你電腦裡的檔案——全部寫下來。
  4. 32–35 分各組分享一項說一個「我以為有備份，其實沒有」的東西。
