02 A 起步．安裝

請一位AI 工程師
住進你的電腦

聊天機器人只能「給你建議」，Claude Code 可以直接在你電腦上建檔案、改程式、存檔、上傳。這個單元帶你一步一步裝好，並完成第一次對話。

  • 分得出聊天型、編輯器型、代理型 AI 工具
  • 在自己的電腦裝好 Claude Code 桌面版
  • 看懂 Claude Code 跳出來的「允許嗎？」
課前自學 約 15 分 課中安裝派對 約 40 分 課後任務 約 10 分
01
先搞懂差別

AI 寫程式工具的三種類型

聊天型

💬 顧問

claude.ai、ChatGPT 的對話視窗。會給你程式碼，但你要自己複製、貼上、存檔、測試。

適合：問問題、查概念

編輯器型

🧑‍✈️ 副駕駛

Cursor、Windsurf、GitHub Copilot。在寫程式的軟體裡幫你補完、修改，畫面上看得到每一行程式碼。

適合：想邊看程式碼邊學的人

代理型．本課主角

🧑‍🔧 包工頭

Claude Code。你說要做什麼，它自己規劃、建檔、執行、測試、存檔，做完再跟你報告。

適合：想專心在「要做什麼」的人

Claude Code vs Cursor：兩個最常被比較的工具

Claude CodeCursor
長什麼樣子對話視窗（桌面 App、網頁、終端機、編輯器外掛都有）寫程式的編輯器（長得像 VS Code），旁邊有 AI 對話
工作方式交代任務，它自己做完一整段你在旁邊看，它邊寫你邊確認
AI 模型Claude可以切換多家模型
對新手不用看懂程式碼就能開始畫面資訊多，需要一點適應
費用需要 Claude 付費方案有免費方案，進階功能要付費

兩個都是好工具，很多人兩個一起用。這門課用 Claude Code，因為它最不需要懂程式碼就能上手。

02
要花多少錢？

選一個 Claude 方案

Claude Code 需要付費方案。價格和額度常調整，請以 官網價格頁 為準。

免費版

可以在 claude.ai 聊天，但不能用 Claude Code。適合先試試跟 AI 對話的感覺。

建議從這裡開始

Pro

可以使用 Claude Code。一般練習、做小工具通常夠用。用完額度要等一段時間才會恢復。

Max

額度高很多，適合每天大量使用、同時做好幾個專案的人。確定自己會常用再升級。

講師的經驗：一開始用 Pro 就夠了。等到你常常「做到一半額度用完」，再考慮升級。
03
一步一步來

安裝 Claude Code 桌面版

選你的電腦，照著做。每做完一步就打勾，卡住了就點「卡住了？」。

  1. 卡住了？

    公司電腦跳出「需要管理員權限」：請 IT 幫忙安裝，或改用自己的電腦。

  2. 卡住了？

    Windows 跳出「Windows 已保護您的電腦」：確認下載網址是 claude.ai 後，按「其他資訊」→「仍要執行」。

  5. 卡住了？

    找不到 Code 分頁：確認 App 已更新到最新版，而且帳號是付費方案。介面若有調整，以官方說明為準。

  1. 卡住了？

    跳出「無法打開，因為來自未識別的開發者」：到「系統設定」→「隱私權與安全性」，按「強制打開」。

官方安裝說明：Claude Code 文件。畫面和步驟若與官方不同，以官方為準。

04
第一個作品

5 分鐘做出一個網頁

裝好之後，把下面這段話複製貼給 Claude Code。

請在這個資料夾做一個「我的自我介紹」網頁：
1. 一個 index.html 檔案就好，不要用任何框架
2. 放我的名字（先用「小明」代替）、三個興趣、一句座右銘
3. 配色溫暖一點，手機和電腦都好看
4. 做完告訴我：怎麼在瀏覽器打開它？

你會看到：Claude Code 說它要「建立 index.html」，然後問你允不允許。按允許之後，資料夾裡就真的多了一個檔案。用瀏覽器打開它，那就是你的第一個網頁。
再玩一步：對它說「背景換成深藍色，名字加上彩虹漸層」，再重新整理瀏覽器看看。這個「說 → 看 → 再說」的循環，就是 Vibe Coding。
05
最重要的一件事

它問「允許嗎？」的時候

Claude Code 在修改檔案、執行指令之前，預設會先問你。這是保護你的安全帶，不是囉唆。

放心允許

建立或修改專案資料夾裡的檔案、看檔案內容、開啟本機預覽。

先問清楚

安裝套件、上傳到 GitHub、動到專案資料夾以外的地方。問它：「這一步是要做什麼？為什麼需要？」

直接拒絕

刪除一大堆檔案、看起來像亂碼的長指令、要你輸入密碼、「強制」覆蓋什麼東西。

06
進階．可以先跳過

終端機：電腦的「文字遙控器」

你偶爾會看到 Claude Code 在執行像 git status 這樣的文字指令。那就是終端機的語言。你不用自己打，但認得的話會安心很多。

想用終端機版 Claude Code？（進階）

終端機版功能最完整，適合想更進一步的人。安裝指令以官方文件為準，目前是：

Mac：打開「終端機」貼上

curl -fsSL https://claude.ai/install.sh | bashcurl -fsSL https://claude.ai/install.sh | bash

Windows：打開「PowerShell」貼上

irm https://claude.ai/install.ps1 | iexirm https://claude.ai/install.ps1 | iex

裝好後，先用 cd 進入專案資料夾，再輸入 claude 就能開始。

資安小提醒：「從網路下載一段程式直接執行」是很強大的動作。只貼官方網站上的指令，不要貼網路上來路不明的教學裡的指令。
07
課中工作坊

安裝派對

兩人一組當「安裝夥伴」，一起完成、一起做出第一個網頁。

課中．約 40 分　準備：每人紅、綠便利貼各一張。

  1. 0–5 分跟旁邊的人組成安裝夥伴。一個人操作時，另一個人念步驟、幫忙看。
  2. 5–25 分照第 03 段完成安裝。卡住超過 3 分鐘就把紅色便利貼貼在螢幕上，助教會過來。完成的人貼綠色，去幫紅色的人。
  3. 25–35 分複製第 04 段的指令，做出自我介紹網頁，再用自己的話改一次樣式。
  4. 35–40 分兩人互看對方的網頁，各說一個「我會想請 AI 再改的地方」。
