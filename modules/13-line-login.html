13 D 進階選修．LINE 登入

最好用的登入，
坑也最多

在台灣，幾乎每個長輩手機裡都有 LINE。用 LINE 登入，不用記密碼、不用收驗證碼，是講師所有教會系統的共同選擇。但它也是講師踩坑最多的地方：光是「LINE 登入＋裝成手機 App」，就踩了十個不會報錯、但使用者那邊是壞的的坑。

  • 認得五個最常見、最隱形的 LINE 登入坑
  • 學會把踩過的坑寫成交接文件，交給 AI

同事說「我登入不了」，而程式沒有報錯

模擬 LINE 登入最常見的四個坑：回呼網址沒登記、LINE 內建瀏覽器開不起來、登入後跳錯頁、憑證過期。每一個都不會報錯。

01

LINE 登入就像去櫃台換證

你的網站不會碰到使用者的 LINE 密碼，全程由 LINE 負責確認身分。按「下一步」看流程。

為什麼要「回程票」再換一次？回程票會出現在網址上，可能被別人看到。所以它只能用一次、很快就過期，真正的身分資料由伺服器在背後向 LINE 換。state（防偽印章）則確認回來的人，就是剛剛出發的那個人。
02
十個坑精選

五個「看起來好了，其實是壞的」

這些都不會跳錯誤訊息。你以為功能完成了，使用者那邊卻卡住，而且通常不會有人回報。

03

把坑寫成交接文件，交給 AI

講師第一次做 LINE 登入，前前後後修了很多次。搞定之後，講師請 Claude Code 把整套做法和十個坑整理成一個可以整包帶走的工具包，附上交接文件，準備給其他專案用。每個坑都寫清楚：

  • 症狀：使用者會看到什麼
  • 原因：為什麼會這樣
  • 驗收：怎麼確認有沒有做對

之後要在其他專案加同樣的功能，就把這份文件交給新對話照著做、逐條驗收。講師的靈修日記就是這樣一次補上了「另一個專案踩過的四個坑」。同樣的坑，不用再從頭摸索一次。

這不只適用於 LINE 登入。任何你花了很多時間才搞定的功能，都值得請 AI 寫一份交接文件。這是 Vibe Coding 裡最被低估的技巧。

課後加裝．約 90 分

把 LINE 登入和通知，接到你的登記系統

LINE 場的主軸是單元 12 的 AI 小秘書；做完之後，可以照這一段自己把 LINE 登入和通知加到單元 10 的登記系統。系統會變成「用 LINE 登入」，管理者改了狀態，本人會收到 LINE 訊息。

🧩 三個零件

  1. LINE Developers：同一個 Provider 底下建兩個 channel。LINE Login 負責「確認你是誰」，Messaging API（官方帳號）負責「推訊息」。
  2. 兩支後端小程式（Supabase Edge Functions）：line-login 拿一次性代碼換登入身分；line-notify 在狀態被改時推訊息。秘密金鑰只放在這裡。
  3. 資料庫觸發（Database Webhook）：登記一被改，就叫 line-notify 起來工作，並附上暗號，別人冒充不了。

步驟都寫在範本的 LINE.md，照著做就好，不用裝任何指令工具。LINE 的畫面看圖解：LINE Developers，Supabase 的畫面看圖解：Supabase。

最容易出事的兩件事
① Channel secret 和存取權杖寫進 config.js 或貼上 GitHub：它們只能放在 Supabase 的 Secrets。
② 兩個 channel 建在不同的 Provider：LINE 給的使用者代號會不一樣，通知永遠送不到，而且不會有任何錯誤訊息。
一個系統只選一種登入方式。同一個人先用 Email、後來改用 LINE，會變成兩個帳號，舊的登記在另一個帳號底下。

怎麼分組自己做；測試通知時，請一位朋友或家人當使用者

要準備單元 10 已經能用 Email 登入的登記系統、手機上的 LINE、LINE Developers 帳號（用自己的 LINE 登入就有）

做完要交出用 LINE 登入的系統，組員送出登記、你改成「已確認」後，組員的手機收到 LINE 訊息

課後自學．約 90 分（卡住了到課後問答找講師）

  1. 步驟 1先看第 01、02 段：「去櫃台換證」的流程，和五個不會報錯的坑。
  2. 步驟 2LINE Developers：建 Provider、LINE Login channel（填 Callback URL）、Messaging API channel，再把官方帳號連到 Login channel（LINE.md 第 1 步）。
  3. 步驟 3Supabase：設定 Secrets、貼上兩支 Edge Functions（line-login 關掉 Verify JWT）、建 Database Webhook（第 2 步）。
  4. 步驟 4config.js 改成 login: 'line'、填 Channel ID，push；用 LINE 登入、加好友，把「管理者設定碼」設成管理者（第 3、4 步）。
  5. 步驟 5互測：組員用 LINE 登入送一筆；你把它改成「已確認」，看他的手機有沒有收到。門禁測試照舊：他看不到你的資料。
  6. 步驟 6照第 05 段，把卡最久的地方寫成交接文件，放進專案的 docs/。
