03
最常見的坑

排程的時區陷阱

Vercel 這類平台的排程用的是國際標準時間（UTC），台灣比它快 8 小時。拉拉看：

UTC 0 點 → 台灣 8 點

小秘書真實的排程設定

每天提醒：   "0 0 * * *"   → UTC 0 點  = 台灣早上 8 點
每週摘要：   "0 0 * * 5"   → 週五 UTC 0 點 = 台灣週五早上 8 點

這串「0 0 * * *」叫 cron，五個位置依序是：分、時、日、月、星期。看不懂沒關係，請 Claude Code 翻譯就好。

⚙️ 規則固定的事

  • 每天早上 8 點檢查今天的待辦
  • 每週五整理一週摘要
  • 把資料存進資料庫
這就是講師 CLAUDE.md 守則第 5 條：能用程式判斷的，就不要問 AI。程式每次結果都一樣、不花錢；AI 貴又不一定每次一樣，只用在真正需要判斷的地方。
05
金鑰清單

一個 LINE Bot 需要幾把鑰匙？

鑰匙做什麼用放在哪
LINE Channel Secret確認訊息真的是 LINE 送來的，不是別人偽造的Vercel 環境變數
LINE Access Token讓程式可以回覆、主動推播Vercel 環境變數
Claude API Key請 AI 做分類Vercel 環境變數
Supabase 萬能鑰匙程式在伺服器端讀寫資料Vercel 環境變數（絕不進網頁）

專案裡只放 .env.example，列出這幾把鑰匙的名字，沒有值。單元 6 教過的規矩，在這裡全部用得上。
